# GLAVAT STUDIO

**Эмоции, которые хочется открыть.**

GLAVAT STUDIO — конструктор цифровых приглашений с персональными ссылками и сбором ответов гостей.

## Возможности

- Шесть событийных оформлений: классика, свадьба, день рождения, встреча, новоселье и семейный праздник.
- Двенадцать шрифтов и живой предпросмотр.
- Свободный текст, дата, время, место и фотография с автоматическим сжатием.
- Скачивание готовой открытки в HTML.
- Сохранение до десяти черновиков в текущем браузере.
- Публикация приглашения по отдельной ссылке для гостей.
- RSVP: «Буду», «Не смогу», «Пока не знаю», число гостей и комментарий.
- Личная ссылка организатора: просмотр ответов, редактирование опубликованного приглашения, удаление и экспорт списка гостей в CSV.
- Адаптивный интерфейс для телефонов и компьютеров.

## Как пользоваться

1. Открой сайт и собери приглашение.
2. Нажми «Создать ссылку».
3. Отправь гостям ссылку для гостей.
4. Сохрани личную ссылку организатора отдельно и никому из гостей её не пересылай.
5. По личной ссылке смотри ответы, меняй текст и оформление или скачивай список гостей.

Черновики хранятся только в браузере, где были созданы. Опубликованные приглашения и ответы хранятся онлайн до удаления приглашения. Личная ссылка организатора содержит секретный ключ доступа в URL-фрагменте; браузер удаляет его из адресной строки после сохранения.

## Архитектура

- **Frontend:** HTML, CSS и JavaScript; публикация через GitHub Pages.
- **API:** Node.js + Express на Railway.
- **Database:** PostgreSQL на Railway; данные хранятся на подключённом постоянном томе.
- **CI:** GitHub Actions проверяет синтаксис, запускает тесты API, публикует сайт и выполняет сквозную проверку API.

## Разработка API

Из каталога `api`:

```bash
npm install
npm test
npm start
```

Для запуска API требуется переменная окружения `DATABASE_URL`. Сервис создаёт таблицы и индекс при старте.

Сквозная проверка работающего API:

```bash
API_BASE=https://glavat-studio-api-production.up.railway.app npm run smoke-test
```

## API endpoints

- `GET /healthz` — состояние API и базы данных.
- `POST /api/invites` — создать приглашение.
- `GET /api/invites/:id` — открыть публичное приглашение.
- `PUT /api/invites/:id` — изменить приглашение (требуется owner token).
- `POST /api/invites/:id/rsvps` — отправить ответ гостя.
- `GET /api/invites/:id/rsvps` — получить ответы (требуется owner token).
- `DELETE /api/invites/:id` — удалить приглашение и ответы (требуется owner token).

## Проверки безопасности

- Owner token генерируется криптографически стойким генератором; в базе хранится только SHA-256-хеш.
- Доступ организатора проверяется через Bearer token и сравнение хеша с постоянным временем.
- Данные проверяются и ограничиваются по длине; публичные запросы ограничены rate limit.
- CORS разрешает домен сайта и локальные адреса разработки.
- Секрет организатора находится в URL-фрагменте и не отправляется браузером в HTTP-запросе.
