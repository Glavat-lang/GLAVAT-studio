# GLAVAT STUDIO

**Эмоции, которые хочется открыть.**

GLAVAT STUDIO — сервис для создания красивых цифровых приглашений.

## Возможности текущей версии
- Выбор готового шаблона приглашения.
- Создание приглашения с нуля со своим текстом.
- Настройка оформления и просмотр результата.
- Скачивание приглашения в виде HTML-файла.

## Планы развития
- Публикация приглашений по персональным ссылкам.
- Сохранение созданных приглашений.
- Добавление фотографий, музыки и подтверждения присутствия гостей.

Проект находится в разработке.
